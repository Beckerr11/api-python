# 🌐 API Simples em Python

API simples criada com Flask para aprender conceitos básicos de backend.

## 📌 Rotas

### Home

```
/
```

### Usuário

```
/usuario
```

Retorna informações em JSON.

## 🚀 Como executar

Instale Flask:

```
pip install flask
```

Execute:

```
python app.py
```

Abra no navegador:

```
http://127.0.0.1:5000
```

## 🛠 Tecnologias

- Python
- Flask
